How we analyze

Each document gets a likelihood estimate from local signals, then a band. Authorship is not proven. GraphSAGE neighborhood embeddings exist for the document graph only and are not a detection signal. HITS is not part of this product.

  • Stylometry. Type-token ratio, sentence-length burstiness, and character entropy — formulaic text tends to look more uniform and less bursty.
  • Local detectors. Stock-phrase markers, sentence uniformity, and n-gram repetition, each scored 0–1 on the same document.
  • Embedding anomaly. Distance from a human-leaning baseline centroid built inside this same dataset (the most human-scoring documents by stylometry).
  • Stylometry deviation. How far the document’s TTR and burstiness sit from this dataset’s own baseline, not a global internet prior.
  • Logistic blend + interval. Those signals are combined with a weighted logistic mix. Disagreement among core scores widens the uncertainty interval.
  • Three bands. Likely AI-generated, likely human-written, or uncertain when the estimate is mid-range or the interval is too wide.
Estimates are not proof of authorship.
